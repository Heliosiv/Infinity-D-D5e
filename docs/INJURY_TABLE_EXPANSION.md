# Expanded Critical Injury Table V3

New injury rolls use **30 outcomes on 1d100**, up from 18. Open **Infinity → Injuries → Injury table** to browse and search every outcome, recovery rule, and automation note.

All 18 existing outcomes remain. Twelve new temporary outcomes split some temporary and minor-injury bands. Lost Limb, Loss of Eye, Loss of Hearing, Shattered Knee, Deep Scar, Nerve Damage, Nightmares, and Soul-Shaken keep their previous roll bands. Permanent injuries and injuries that can become permanent have the same odds as V2. This is a variety expansion, not a claim that every other severity category has identical odds: Minor Injury drops from 10% to 3%, and several more debilitating temporary outcomes become less likely.

## New outcomes

Every new outcome applies its listed numeric penalty as a D&D5e Active Effect. Ability-check penalties also apply to skills using that ability. Skill penalties apply to that skill regardless of sense or body side. Strained Shoulder affects melee weapon attacks; it does not depend on which hand makes the attack. Rattled Nerves affects every initiative roll until recovery. Native D&D5e may also include check bonuses in derived passive scores. These are deliberate rules, without conditional first-roll or limb tracking.

No treatment check is required for these new entries. Ordinary recovery removes the effect. Separate injuries stack their numeric penalties, including repeated outcomes, and each recovers independently.

## Saved injuries and compatibility

New rolls save table version 3 in both the GM receipt and the Actor effect. Existing version 2 receipts, effects, queued resolved applications, and treatment retries continue to resolve against the original V2 bands and rules. For example, a saved V2 roll of 35 remains Deep Cut; a new V3 roll of 35 is Pulled Back. Already-approved prompts with no saved dice result use V3 when rolled. Existing injuries are neither rerolled nor migrated. Unsupported table versions are rejected.

Keep `scripts/injury/table-v2.js` as the historical definition for V2 receipts. The current chart combines those original outcomes with the new definitions in `scripts/injury/table-v3.js`; future rule changes must preserve already-recorded versions too.

## Verification and limits

Automated tests cover every d100 face in both versions, all 12 new effect modifiers and recovery durations, unchanged permanent-injury bands, body-region display, GM-authoritative V3 application, V2/V3 treatment, version rejection, and GM table navigation and search. The local browser journey exercises the actual injury controller against a fixture environment. Installed-world rolls, third-party roll replacements, and calendar integration still require verification in Foundry after an authorized deployment.

The original table is still not fully automatic. This expansion does not fix the audit’s older conditional effects, equipment restrictions, or timer-versus-rule mismatches. The new numeric fields follow the official [D&D5e Active Effect Guide](https://github.com/foundryvtt/dnd5e/wiki/Active-Effect-Guide) and [roll formula documentation](https://github.com/foundryvtt/dnd5e/wiki/Roll-Formulas).
