# Infinity D&D5e v0.3.47

This update reorganizes the GM Shops and Downtime workspaces around the work
that needs attention while preserving the existing campaign rules and records.

## What changed

- Shops opens with clear location, shop, open, and attention counts, plus a
  compact summary for the selected market.
- Location search also finds merchants inside each location, and a new **Needs
  attention** filter isolates shops that are closed, empty, or have active
  sessions.
- Shop rows use consistent state badges for opening status, stock, and active
  sessions so a GM can scan the market before opening an editor.
- Downtime separates live block work under **Run** from activity, project,
  research, and location setup under **Prepare**.
- Downtime navigation shows current counts and a contextual guide for each
  section. The live block summary distinguishes characters who are waiting,
  ready for review, or resolved.
- The responsive layouts, keyboard journeys, focus behavior, and accessible
  labels were rechecked across narrow and wide Foundry application windows.

## Upgrade check

Create a Forge Save Point before installing. After restarting the target world,
confirm Infinity D&D5e v0.3.47 is active. Open **Shops** and verify that location
search, **Needs attention**, and shop badges reflect the existing merchant data.
Open **Downtime**, switch between **Run** and **Prepare**, and confirm the saved
activities, projects, research, locations, and any current block remain present.
This release changes presentation and navigation only; it does not migrate or
rewrite those campaign records.
